# Vehicle Rental Management System
## Project Overview
A Python-based Vehicle Rental Management System
that helps manage vehicle rentals, returns,
availability, and rental bill calculations.

## Technologies Used
- Python 3
- Object-Oriented Programming
- Lists and Dictionaries
- File Handling

## Features
- Add new vehicles
- Rent vehicles
- Return vehicles
- Check vehicle availability
- Automatic bill calculation
- 10% discount for rentals of 7 days or more
- Save vehicle data in a text file

## How to Run
1. Open the Code_Base folder.
2. Run main.py using Python.
3. Select an option from the menu.

## Project Structure
- Code_Base: Python source code and data files.
- Documentation: Project report and presentation.
